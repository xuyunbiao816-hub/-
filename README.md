# 花生805词 · 行测词语记忆器

这是基于“花生800词上下册完整版805条结构化题库”重新开发的独立 PWA。只使用 HTML、CSS、原生 JavaScript、JSON、`localStorage`、Web App Manifest 和 Service Worker，不依赖旧版100词进度，也不包含后端或外部接口。

## 启动

在 `huasheng-805-memory` 文件夹中运行：

```bash
python -m http.server 8081
```

然后访问：`http://localhost:8081/`

手机与电脑连接同一 Wi-Fi 时，可在电脑运行：

```bash
python -m http.server 8081 --bind 0.0.0.0
```

手机访问 `http://电脑的IPv4地址:8081/`。

## 安装与离线使用

PWA 安装和 Service Worker 需要 HTTPS，或电脑本机的 `localhost`。通过手机访问局域网中的 `http://电脑IP:8081` 时，普通网页可以使用，但大多数浏览器不会允许安装PWA或启用离线缓存。

将项目部署到任意支持 HTTPS 的静态网站服务后：

- Android Chrome/Edge：打开网站，使用浏览器菜单中的“安装应用”或“添加到主屏幕”。
- iPhone/iPad Safari：点击分享按钮，选择“添加到主屏幕”。
- 首次完整打开后，页面、样式、脚本、805条题库和图标会缓存到设备，可离线再次打开。
- 发布新版本后，重新打开应用会安装更新后的缓存版本。

## 数据与唯一键

- 完整题库共805条：成语688条、实词117条。
- 学习进度、错词状态、复习次数、当天学习批次和队列全部使用 `记录ID`。
- `词语` 和 `成语` 字段只用于界面显示与搜索，绝不作为进度唯一键。
- 导出的进度JSON只包含以 `记录ID` 为键的学习状态，不重复导出题库。
- 旧版以成语名称为键的进度文件不会自动迁移或导入。

## 功能

- 今日学习：到期复习、新词学习两个独立模块，可自主选择顺序和随时切换。
- 新词批次：每天默认20条，完成后可以继续加入下一批20条。
- 类型区分：学习卡、错词本、全部词库和详情均标注成语或实词；全部词库支持类型筛选。
- 四档评价、错词本、搜索、组别筛选、进度导入导出和二次确认重置。
- PWA：支持安装到手机桌面，并在首次在线加载完成后离线打开。

“已掌握”定义为当前复习间隔达到7天及以上。学习数据只保存在当前浏览器中。
