# 1000词 · 行测词语记忆器

这是基于“四海高频成语实词1000词”上下册 PDF 制作的独立 PWA。PDF 标题称1000词，但目录分组计数与正文实际均为993条：成语842条、实词151条。本项目完整使用这993条，不补造数据，不修改原书释义和例句。

## 启动

在 `huasheng-1000-memory` 文件夹中运行：

```bash
python -m http.server 8082
```

然后访问：`http://localhost:8082/`

手机与电脑连接同一 Wi-Fi 时，可在电脑运行：

```bash
python -m http.server 8082 --bind 0.0.0.0
```

手机访问 `http://电脑的IPv4地址:8082/`。

## 安装与离线使用

PWA 安装和 Service Worker 需要 HTTPS，或电脑本机的 `localhost`。部署到 HTTPS 静态网站后：

- Android Chrome/Edge：使用浏览器菜单中的“安装应用”或“添加到主屏幕”。
- iPhone/iPad Safari：点击分享按钮，选择“添加到主屏幕”。
- 首次完整打开后，页面、脚本、993条题库和图标会缓存到设备。

## 数据与唯一键

- 完整题库共993条：上册成语498条、下册成语344条、下册实词151条。
- 分为81个组，所有进度使用新版 `记录ID` 作为唯一键。
- 本版使用独立的 `localStorage` 键，不读取或覆盖805词版进度。
- 导出的进度JSON只包含学习状态，不重复导出题库。

## 功能

- 今日学习：到期复习和新词学习可自主选择顺序。
- 每天默认20条新词，完成后可继续加入下一批。
- 四档评价、错词本、搜索、类型和组别筛选、进度导入导出、二次确认重置。
- 原生朗读：卡片出现时可读词语；展开答案后只读原书释义，不自动读例句。
- 每条例句旁有独立小喇叭，用户点击后才朗读该条例句。
- 成语首次学习保留释义和例句；后续复习先进行语境判断，再显示核心意思和强调重点。
- PWA：首次在线加载完成后支持离线打开。

如需补充近义词辨析，可在单条题库记录中使用可选字段：`similarWords`（字符串数组）和 `contrast`（一句关键区别）。字段缺失时自动使用现有例句进行语境判断，不影响学习流程。

“已掌握”定义为当前复习间隔达到7天及以上。学习数据只保存在当前浏览器中。
